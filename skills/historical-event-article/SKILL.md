# 📜 历史纵深型深度文章生成器

## 概述

> **历史不会重复，但它踩着相同的韵脚。——马克·吐温**

本skill合并两大能力为一个独立管道：

| 组件 | 来源 | 角色 |
|------|------|------|
| 🔍 **研究引擎** | `history-mirror` 三镜分析法 | 在历史中找到当代事件的结构性映射，提取可迁移规律 |
| ✍️ **写作引擎** | `tianya-blogger` 六特征写作法 | 将研究发现转化为天涯神贴风格的传播型文章 |

**一句话价值**：输入一个当代事件，输出一篇「有2500年历史纵深 + 天涯神贴传播力 + 自动平台适配」的深度文章。

### 与其他skill的关系

- 本skill是 `history-mirror` + `tianya-blogger` 的**统一入口**
- 如果你只需要历史分析（不要文章）→ 直接用 `/history-mirror`
- 如果你只需要天涯风格写作（自己做研究）→ 直接用 `/tianya-blogger`
- 如果你想要从研究到成文一气呵成 → **用本skill**
- 本skill内部自动调用上述两个skill的方法论，无需手动链式调用

## 核心分析框架：三镜 × 六特征

### 研究层：三镜分析法（来自 history-mirror）

**第一镜·铜镜 🪞**：拆解当代事件的结构性要素——触发因素、核心主体、作用机制、影响范围、时间尺度、关键变量。将具体事件抽象为"历史上可映射的结构"。

**第二镜·史镜 📜**：六维并行搜索历史案例——纵向历史（同一国家/地区）、横向比较（其他国家）、深层结构（跨时空同构）、反面案例（不同选择→不同结果）、学术研究、当代映射。

**第三镜·人镜 👤**：提炼人性规律——认知偏误、激励结构、群体行为模式、预警信号、关键转折点。

### 写作层：六特征写作法（来自 tianya-blogger）

| 特征 | 核心技法 |
|------|---------|
| **内部人视角** | 以"我研究了N个历史案例"的身份发言，而非"据报道" |
| **系统性框架** | 给历史规律一个简洁命名（如"五阶段铁律"），让读者可以带走 |
| **反常识判断** | "大家都以为技术封锁能阻止对手——但2500年历史说了相反的话" |
| **大胆预测** | 基于历史规律给出有条件的判断，不是算命，是"如果X，则Y" |
| **第一人称叙事** | "我翻完XX年历史后发现……""说实话，我看到这个数据的时候是震惊的" |
| **连载式深度** | 每篇文章留钩子："这篇文章讲清楚了X，下一篇我会讲Y" |

## 六步工作流

### 第一步：接收事件，爬升抽象阶梯

用户输入一个当代事件。你的第一件事不是搜索，而是**拆解 + 抽象化**。

**事件拆解表**（必填）：

| 结构性要素 | 具体内容 | 抽象化描述（可用于历史映射） |
|-----------|---------|--------------------------|
| 触发因素 | [具体触发事件] | [抽象触发机制] |
| 核心主体 | [具体参与方] | [抽象主体类型] |
| 作用机制 | [具体传导路径] | [抽象作用逻辑] |
| 影响范围 | [具体影响区域/行业] | [抽象影响层级] |
| 时间尺度 | [短期/中期/长期] | [时间维度] |
| 关键变量 | [影响走向的关键因素] | [抽象变量类型] |

**如果用户输入过于宽泛**，主动聚焦。示例：

> "这个主题很宏大。历史可以从很多角度切入。你更关心哪个方面？
> - 走向判断？（历史类似事件的演变结果）
> - 应对策略？（历史上成功的应对方案）
> - 风险预警？（历史上类似情境下的崩溃信号）
> - 周期规律？（这类事件的循环节律）"

### 第二步：六维历史搜索（核心研究）

基于抽象化的事件结构，六维并行搜索：

```
□ 维度1：纵向历史 — [抽象机制] + [国家/地区] + 历史案例
□ 维度2：横向比较 — [其他国家] + [事件类型] + 经验教训
□ 维度3：深层结构 — [抽象机制] + 历史规律 + 周期
□ 维度4：反面案例 — [事件类型] + 成功 vs 失败 对比
□ 维度5：学术研究 — [事件类型] + 经济史/政治学 + 研究
□ 维度6：当代映射 — [近年类似事件] + 复盘分析
```

**每轮并行 3-5 次 WebSearch。第一轮广撒网定位，第二轮深挖候选案例，第三轮学术交叉验证。**

### 第三步：筛选与匹配历史案例

从搜索结果中筛选 **2-5 个最相关案例**，标准：

- **结构性匹配度（40%）**：核心机制是否相似？
- **结果可观测性（25%）**：事件是否经历了完整周期？
- **信息丰富度（20%）**：是否有学术研究和分析材料？
- **差异警示价值（15%）**：即使不完全匹配，差异本身是否提供警示？

匹配度评级：★★★★★ 高度匹配 → ★ 仅供参考

### 第四步：提炼跨案例规律

从历史案例中提炼**可迁移规律**：

| # | 规律/模式 | 出现频率 | 在当前情境的适用性 |
|---|----------|---------|-----------------|
| 1 | [规律描述] | N/N 案例 | 高/中/低 + [原因] |
| 2 | [...] | [...] | [...] |

同时提炼：
- **常见决策偏误**：历史上的决策者犯了哪些错？
- **预警信号清单**：哪些信号出现意味着风险升级？
- **关键转折点**：什么因素最终改变了走向？

### 第五步：天涯风格写作

用「反常识 → 框架 → 证据 → 预测 → 余味」的结构写作。

**标题公式**：
```
[主体]+[历史纵深判断]："重新理解XX：历史不会重复，但它踩着相同的韵脚"
[时间]+[历史窗口]："站在历史的十字路口：过去N次XX给今天的启示"
[反常识提问]："你以为这次不一样？历史上N次'这次不一样'最后都一样"
[身份]+[历史洞察]："一个翻遍XX年历史资料的人，告诉你接下来会发生什么"
```

**正文结构铁律**：
```
你们都以为是A → 但我告诉你其实是B 
  → 证据1：历史上的XX案例
  → 证据2：历史上的YY案例
  → 证据3：如果你还不信，想想ZZ
  → 基于以上，未来会发生D
  → 但前提是E不变
```

**核心技法**：
1. **判断句驱动**：每个段落以判断开头，以证据收尾
2. **层层剥洋葱**：先表面反常识 → 再揭示机制 → 最后触及结构性本质
3. **金句节奏**：每300-500字一个"读者想截图"的金句
4. **"说白了"时刻**：至少一处用通俗比喻把复杂机制说清楚
5. **"你品，你细品"时刻**：给出事实不做判断，让读者自己得出结论
6. **历史案例口语化**：用「说白了，这和XX年XX事件本质上是一回事」而非学术引用

**六大开头选一**：
- 身份+判断："我花了三周翻遍了过去200年四次技术革命的就业数据……"
- 反常识冲击："这可能是你看过的最让你不安的历史分析……"
- 数据震撼："过去十年，这个数据变了XX倍，但你的认知还停在十年前……"
- 细节切入："公元前197年的一封埃及诏书，和2026年的一份美国行政令……"
- 框架预告："今天我用三个历史案例，一个分析框架，讲清楚XX……"
- 坦白式："说实话，写这篇文章我是犹豫的，因为结论太反常识……"

**四大结尾选一**：
- 金句收尾："周期从不爽约，它只是迟到。"
- 预言式："X个月后回头看，我们会发现……"
- 提问式："你觉得呢？评论区告诉我。"
- 留钩子："这篇文章讲清楚了X，下一篇我会讲Y。"

### 第六步：确定平台 + 导出Word

**默认平台：公众号**（2000-3500字，完整框架展开）。

**平台速查**：

| 平台 | 字数 | 核心特征 |
|------|------|---------|
| 公众号 | 2000-3500 | 完整框架展开，第一人称叙事 |
| 知乎 | 2000-5000 | 以问题为切入点，逻辑严密，收藏友好 |
| 今日头条 | 1000-1800 | 结论前置，口语化，**必须同步3-5条微头条** |
| 微博 | 500-1200 | 每150字一个金句，转发即表态 |
| 小红书 | 1000-1500 | "我发现"视角，emoji友好 |
| B站专栏 | 1200-2500 | 人设感强，UP主视角 |

**Word导出**：文章定稿后**必须**自动导出。排版规格：
- 字体：微软雅黑
- 正文：11pt，深灰 #2C2C2C（厚重感）
- 金句/引用：深棕 #8B4513 加粗（老派智慧感）
- 导语/摘要：加粗
- 文件命名：`[话题简称]-历史纵深-[平台名]版.docx`

**实现方式**：使用 `python-docx` 库生成格式化Word文档。确保系统已安装 `python-docx`（`pip install python-docx`）。

## 天涯风格语言特征

- **口语化但精准**：像在说话，但每个判断有精准边界
- **长短句节奏**：短句制造冲击，长句展开论证。关键判断永远用短句
- **反问句**："你真的以为封锁是为了国家安全？"——用反问责创造思考空间
- **适度江湖黑话**："说白了""说穿了""这里面的门道""行内人都知道"
- **避免AI感**：适当使用"说实话我写到这里自己也觉得有点震撼""反正我是这么看的，对不对你自己判断"
- **"我"的责任**：用"我"发言意味着为判断承担人格担保——要么用"我判断"，要么用"数据显示"

## 判断力自检

文章完成后必须过以下五关：

1. ☐ 有没有至少三个"读者没想到但觉得有道理"的判断？
2. ☐ 有没有至少一个"读者想截图转发"的金句？
3. ☐ 读者看完后，能不能用一两句话复述你的核心框架？
4. ☐ 历史类比是否有明确的边界说明（"这次和XX年有本质不同，因为……"）？
5. ☐ 预测是否有条件触发条件（而非无条件的"一定会XX"）？

---

## 注意事项

1. **不是预测工具**：基于历史规律的场景推演 ≠ 预测。始终用"如果X条件满足，则历史规律Y更可能适用"的框架
2. **必须说明类比边界**：每篇文章必须指出当前事件与历史案例之间的关键差异
3. **反常识不是反事实**：每个反常识判断必须有逻辑链或数据支撑
4. **平台合规**：天涯神贴的精神是"说真话"，但表达需适配平台规则。用框架和逻辑表达尖锐观点，不用情绪化攻击语言
5. **引用标注**：引用数据、报告、事件时标注来源
6. **默认平台**：未指定时默认公众号，文末注明可切换
